Year 9 Computer Science revision cards

HTML and CSS:

What does HTML stand for?
HyperText Markup Language.
What is HTML?
It is the standard markup language for creating web pages.
What does CSS stand for?
Cascading Style Sheets.
What is CSS?
The language used to style a web page
What does a CSS rule consist of?
A selector and a declaration block.
Give 1 good other option to learn HTML.
You can use a text editor like Notepad (PC/laptop) or TextEdit/Notes (MacOS).
What does CSS control?
It controls the layout, colours, typography, and responsive behavours of your websites.
